# こおりくんの大冒険～氷の城と大きな竜～

こおりくんシリーズの メダルゲーム。こおりくんたちが 氷の 城の てっぺんで ジャックポットを ねらう、プッシャー＋JP 抽選の 大型メダルゲームを ブラウザで 1 人で 遊べる ように した もの。もとは ユーザーの 企画書 (2026-11-17)。

公開ページ: https://taku3482yasu-web.github.io/koori-medal/

## 遊び方
- プッシャーの 上を タップ (クリック) で その 位置に メダルを 入れる。長押しで 連射。スペースキーでも 入れられる (← → で ねらう 位置)。メダルは いちばん 上の 動く プッシャーの 上に 落ちる。
- チャッカー (L・CENTER・R) に 入ると 保留 +1 (「入賞！ 保留 +1」と 出て、光が 液晶の 保留ランプへ とぶ)。液晶に 保留の わくが 4 つ。
- 氷の 塔: どの 段にも 払い出し・上へ・落下 の 3 つの 穴。ボールが 止まった 穴で きまる。左に いま して いる こと、右に 塔の すすみ。
- 上段の 入り口の チャッカー (左・中央・右) に 入ると 液晶スロットの 抽選 (保留 4 個。青 → 水色 → 金 で 期待度 アップ。おかがっぱが 出ると チャンス)。
- スロットで ボールが 出ると、おかがっぱが ボールを 氷の 塔へ。3 段で「上へ」「払い出し」「落下」。おにおにが 塔の 途中で 待ちかまえる。てっぺんで JP ルーレット。
- JP ルーレット (24 ポケット・JP 1 つ・もう一回 あり)。JP ポケットで「こおりJP」(投入で プールが ふえる。一部は フィールドに 放出して 山が くずれる)。
- ビックボスチャレンジ: ボスゲージが たまるか、スロットで ボス図柄が そろうと 発生。強敵ルーレットで ボスが きまり (ハル麒麟・金剛鬼・おにおに・おにおに・怪・シーシャ・ナイテイ・ナイナイ・アソボレアス)、60 秒 以内に 投入と チャッカー入賞で 攻撃。1 人 プレイでは ほかの 席を CPU の 仲間が 手伝う。倒すと ビックボスメダルタワーが 爆散して メダルが ふる (基本分 + 貢献ボーナス・MVP は ボール)。
- 台には ボールが ある。こおりボール (水色) を 落とすと 20 枚、スペシャルボール (金・★) を 落とすと スペシャルルーレット (枚数・塔の ボール・ボスゲージ・JP ルーレットへ 直行)。スロットの「ボール追加」で ふえる。
- ボスを 倒すと、積まれた ビックボスメダルタワーが クレーンで 台に はこばれて 置かれ、爆散する。
- 手前から 落ちた メダルが 払い出し。下段の 左右の はしの 穴に 落ちると もどらない (ボールは 台に もどる)。
- メダル・JP プール・フィールドの メダルは ブラウザに 保存。メダルが なくなったら ふるカワが 50 枚 くれる。

## 決まった こと (2026-11-17 ユーザー)
- タイトル「こおりくんの大冒険～氷の城と大きな竜～」
- 払い出しは 甘め 95% くらい (tools/test.js で でたらめに 入れて 92〜98%・中央を ねらうと 少し よい)
- キャラの 役割は 企画書の 案どおり (こおりくん = 主役・おにおに = 敵役・おかがっぱ = 助け役)

## 決まった こと (2026-11-18 ユーザー)
- 横画面・ゲーセンの 大型機の 席に すわった 目線。メダルは 厚みの ある 立体 (物理を 2.5D に した)。メダルは 大きく・刻印は うき彫り
- 画面は すっきり: ふだんは 台と 液晶だけ。氷の 塔・ルーレットは 始まったら その 画面へ うつる
- ルーレットは カジノの ように 玉を 回して ポケットに 入れる ルーレットマシン (JP ルーレット・スペシャルルーレット)
- 台に ボール (落とすと スペシャルルーレットや コイン)
- ボスを 倒すと 積まれた タワーが クレーンで はこばれて 台に 置かれる
